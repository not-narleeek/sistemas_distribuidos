# Guía paso a paso para la Tarea 3

Esta guía resume las actividades necesarias para cumplir con los objetivos de la Tarea 3, desde la recolección de información hasta la ejecución completa del pipeline batch basado en Hadoop + Pig.

## 1. Preparación inicial

1. **Revisar requisitos del host.** Asegúrate de contar con Docker Engine ≥ 20.10, soporte para `docker compose` v2, GNU Make y Python 3.10 o superior.
2. **Clonar y posicionarse en el repositorio.** Dentro del directorio `sistemas_distribuidos`, confirma que los submódulos relevantes (por ejemplo, `distributed-batch-ling`) están presentes.
3. **Verificar acceso a los datos fuente.** Identifica si usarás un volcado CSV/Parquet con columnas de respuestas (`id_pregunta`, `respuesta_texto`, `origen`, `ts_creacion`) o un registro de tráfico (`timestamp`, `operation`, `status`, `topic`, etc.). Ten a mano las credenciales si requieres conectarte a MongoDB.

## 2. Validación y exploración de datos

1. **Inspeccionar las cabeceras del dataset.** Usa `head` o un editor para confirmar los nombres de columnas y decidir si el modo `responses` o `traffic` es el adecuado.
2. **Ejecución en seco del exportador.**
   ```bash
   python distributed-batch-ling/ingestion/exporter.py \
     --input /ruta/a/datos.csv \
     --output-dir distributed-batch-ling/ingestion/output \
     --dry-run --verbose
   ```
   Ajusta los parámetros (`--input-schema`, `--traffic-text-columns`, `--traffic-origin-map`, etc.) hasta que no aparezcan errores de validación.
3. **Preparar stopwords personalizadas (opcional).** Si necesitas una lista distinta de `stopwords_es.txt`, edítala en `distributed-batch-ling/pig/` antes de iniciar el pipeline.

## 3. Puesta en marcha del entorno Hadoop + Pig

1. **Construir y levantar servicios.**
   ```bash
   make up
   ```
   Este paso monta los contenedores (NameNode, DataNode, ResourceManager, HistoryServer y Pig).
2. **Inicializar HDFS.**
   ```bash
   make hdfs-init
   ```
   El proceso espera a que el NameNode salga de *safe mode*, crea directorios de entrada/salida y publica `stopwords_es.txt` en `/data/resources/` dentro de HDFS.

## 4. Ingesta y carga en HDFS

1. **Exportar corpus y subirlos al clúster.**
   ```bash
   make load-data DUMP_PATH=/ruta/a/datos.csv
   ```
   Para datasets de tráfico añade `SCHEMA=traffic` y cualquier ajuste adicional (por ejemplo `TRAFFIC_TEXT_COLUMNS="operation,status,topic"`).
2. **Verificar archivos en HDFS.**
   ```bash
   make hdfs-ls
   ```
   Confirma que `/data/input/yahoo` y `/data/input/llm` contienen los archivos `*_respuestas.txt`.

## 5. Ejecución del análisis batch

1. **Lanzar el pipeline completo.**
   ```bash
   make run-batch
   ```
   Esto ejecuta `wordfreq.pig` para los corpus de Yahoo y LLM, y luego `compare.pig`. Los objetivos individuales (`make run-yahoo`, `make run-llm`, `make run-compare`) están disponibles para depuración.
2. **Supervisar logs.** Revisa `distributed-batch-ling/logs/pig/pig_yahoo.log` y `pig_llm.log` para verificar tiempos y posibles advertencias.

## 6. Recuperación de resultados y comparativas

1. **Descargar artefactos desde HDFS.**
   ```bash
   make fetch
   ```
   Los resultados quedarán en `distributed-batch-ling/artifacts/output/` replicando la jerarquía de `/data/output`.
2. **Generar tablas y visualizaciones.**
   ```bash
   make compare CHART=1
   ```
   Produce `topN` y comparativas en CSV/PNG a partir de los TSV descargados.
3. **Calcular métricas globales.**
   ```bash
   make metrics
   ```
   Obtén tamaños de corpus, número de líneas y duraciones aproximadas del pipeline.

## 7. Cierre y limpieza

1. **Detener los contenedores.**
   ```bash
   make down
   ```
2. **Limpiar artefactos opcionales.** Usa `make clean-logs` o `make clean-artifacts` para reiniciar el entorno antes de una nueva ejecución.

## 8. Entregables de la Tarea 3

- **Resultados procesados:** CSV/TSV y gráficos generados en `distributed-batch-ling/artifacts/`.
- **Documentación:** Informe en LaTeX (ubicado en `docs/batch_analysis/`), actualizado con hallazgos, metodología y comparación Yahoo vs. LLM.
- **Video de demostración (10 minutos):** Mostrar el pipeline corriendo, interpretación de resultados y discusión batch vs. streaming.
- **Repositorio público:** Contener todo el código, scripts de despliegue (`docker-compose.yml`, `Makefile`, `README`) y la guía (`T3.md`).

Sigue estos pasos en orden para garantizar la reproducibilidad del análisis y la entrega completa de la Tarea 3.
